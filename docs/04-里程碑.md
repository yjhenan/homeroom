# 04 · 里程碑

原则：每个 M 结束时应用可运行、可演示；顺序固定，M4 之前不碰 Rust。

## M1 裁剪 + 学生模块端到端

1. 裁剪：删登录/auth/请求层/i18n英文/示例页（清单见 01-架构），默认深色，pre-commit 减负
2. `ClassRepo` 接口 + Dexie 实现（semesters/students/enrollments/settings 四表先落）
3. 学生列表 + 表单 CRUD + 学期切换器（顶部）
4. Excel 模板下载 / 导入（含行级校验）/ 导出；JSON 全量备份导出导入
5. vite 杂项：`server.open:false`

**验收**：`pnpm dev` 无登录页直达学生列表；导入一份真实名单 ≥40 行成功；刷新后数据仍在；JSON 导出再导入数据一致。

## M2 考勤 + 学生 360

1. 考勤录入页（默认出勤、点选循环、备注、离开提示）
2. 考勤历史查询
3. 360 视图骨架 + 考勤 Tab（日历热力 + 出勤率）

**验收**：40 人班级单日考勤 ≤30 秒完成；360 视图考勤数据与录入一致。

## M3 成绩 / 德育 / 值日 / 学期归档

1. 考试管理 + 成绩内联批量录入（含 Excel 粘贴）+ 统计
2. 德育事件流 + 筛选汇总
3. 值日排班周视图 + 评价
4. 文档台账（条目级，附件仅小文件）
5. 学期归档（旧学期只读）+ 新学期复制名册
6. 360 视图补齐成绩/德育/值日 Tab

**验收**：从 Excel 粘贴一列成绩无误入库；切换学期各模块数据隔离；归档学期不可编辑。

## M4 Tauri 集成（最后一步）

1. SQLite 实现 `ClassRepo`，库文件 = exe 同目录 `class.db`（Rust 命令取 exe 路径）
2. 数据迁移：浏览器阶段 JSON → SQLite 导入路径
3. `vite base:'./'` 核验、CSP、窗口细节；附件落磁盘；`backup/` 每周自动快照
4. 打包：裸 exe（非安装包），SmartScreen 提示写进交付说明
5. 打印在 WebView2 下验证

**验收**：朋友机器无 Node 环境双击 exe 可用；class.db 出现在 exe 旁；迁移后数据与 web 阶段一致；拔掉网线功能不受影响。
