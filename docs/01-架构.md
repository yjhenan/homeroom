```
        dexie 实现(M1)                sqlite 实现(M4)
```

## 仓库接口硬规则（两实现可互换的前提）

1. **组件与 store 只准 import `ClassRepo` 类型与实现工厂**，禁止直接 import `dexie` / `@tauri-apps/*`
2. **DTO 纯数据**：id 为字符串（nanoid 12 位）；日期 `YYYY-MM-DD`、时间 ISO 字符串；分数 number；**不出入 Date 对象、Dexie 特有类型、SQL 行对象**
3. 方法 = 一个业务动作，动词开头（`upsertStudents` / `getAttendanceByDate` / `queryScores`）
4. 全量导出 JSON 顶层带 `version` 字段——它是备份格式，也是 web→桌面阶段的**迁移桥**
5. Dexie schema 变更必须升 version 并写 migration，禁止改历史 version 定义

## 目录约定（新增部分）

```
src/
├── repo/
│   ├── types.ts          # ClassRepo 接口 + 全部 DTO
│   ├── dexie.ts          # Dexie 实现（含 schema/migration）
│   └── index.ts          # createRepo() 工厂，按环境返回实现
├── types/business.d.ts   # 与 UI 相关的业务类型（枚举中文标签映射等）
└── views/                # 每模块一目录，沿用 elegant-router 约定
```
