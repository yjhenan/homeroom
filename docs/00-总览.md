# 00 · 总览

## 一句话

班主任的**本地**班级管理工具：把一学期的学生、考勤、成绩、德育、值日记下来，随时调取。

## 背景

- 使用者是单个班主任（开发者朋友），带一个班、一个学期为周期
- 心智模型是「储存卡」：数据是一坨看得见、拷得走的本地文件，不是云服务
- 学校发的名单/成绩是 Excel，工具必须与 Excel 顺畅互通

## 最终交付形态

```
D:\班级管理\            # 朋友自选目录，整个文件夹即"储存卡"
├── 班级管理.exe        # Tauri 打包的裸 exe，绿色免安装
├── class.db            # SQLite 数据库（exe 同目录）
└── backup/             # 自动快照（JSON），按周滚动
```

## 核心用例（按重要性）

1. **快速录入**——考勤一天一屏只点缺席者；成绩按考试×科目表格内联批量录
2. **随手检索**——学生 360 视图：搜名字，一页看全该生考勤/成绩趋势/德育记录
3. **可靠留存**——表单防抖自动落库；全量导出/导入 JSON；Excel 导入导出

## 非目标（明确不做）

- ❌ 家校通知推送（发微信/短信需要第三方服务）
- ❌ 多用户、角色权限（单用户，无登录���
- ❌ 云端同步（只做本地 + 手动备份；接口层预留上云可能，但不实现）
- ❌ 浅色主题（固定深色）
- ❌ 移动端适配（桌面 1920 宽屏优先）
- ❌ 花哨动效

## 开发策略

**web-first**：功能开发期纯浏览器（Vite dev + IndexedDB），Rust/Tauri 一行不碰；
M4 集成期补 SQLite 实现并用 JSON 导出/导入完成数据迁移。详见 [04-里程碑](./04-里程碑.md)。
