# 03 · 模块需求

通用基调：B 端深色、圆角卡片、大字体大行高、信息不拥挤、无花哨动效。

## 首页（轻量）

不做大屏仪表盘。四张信息卡：**班级人数 / 今日异常考勤数 / 本周待录成绩 / 最近备份时间**（异常橙色高亮），加最近录入事件列表（最近 10 条，可点跳转）。核心入口：今日考勤、录成绩。

## 学生管理

- 列表：搜索（姓名/学号模糊）、按状态筛选、排序；列：学号/姓名/性别/家长电话/备注/操作
- 表单：新增/编辑弹窗，字段见数据模型；删除需确认（提示影响的历史记录数）
- **Excel 导入**：下载模板（程序生成带表头空 xlsx）→ 填写 → 导入
  - 模板列：`学号* 姓名* 性别 出生日期 家长电话 住址 备注`
  - 校验：必填缺失、学号与库内重复 → **按行号报错**，一次列全，修完重导
  - 学号已存在时可选「覆盖更新」或「跳过」
- 导出：当前筛选结果 → xlsx

## 考勤

- **录入页（核心交互）**：选日期 → 一屏学生列表默认全「出勤」→ 点某人循环切换 病假→事假→旷课→迟到→早退→出勤；右侧备注抽屉；未保存离开有提示；保存即全量落库
- 历史查询：按日期范围/学生/状态筛选；异常标橙
- 来源：也可从学生 360 视图只看单人

## 成绩

- 考试管理：列表 + 新建/编辑（名称、日期、类型）
- **录入页**：选考试 → 选科目 → 表格内联编辑（方向键/回车移动，类 Excel 手感）→ 支持从 Excel 粘贴整列
- 统计：单次考试按科目 均分/及格率/最高最低/排名；名次并列取最小值
- 趋势：学生 360 视图内按科目折线图（ECharts）

## 德育纪律

- 事件流：按时间倒序列表 + 快速新增（学生多选、日期、加减分、分类、描述）
- 筛选：按学生/分类/方向；个人加减分汇总

## 值日卫生

- 排班：周视图（周一~周日 × 值日组），支持按周复制；组内学生多选
- 评价：按天打 good/ok/poor + 备注；周/学期汇总视图

## 文档台账

- 条目 CRUD：标题、分类、日期、摘要；搜索
- 附件：web 期存 IndexedDB（限制单文件 ≤10MB 提示）；M4 迁磁盘

## 学生 360 视图（核心页面）

路由 `/student/:id`。头部：基本信息卡 + 学期切换。Tab：

1. **考勤**：日历热力（月视图，异常着色）+ 出勤率
2. **成绩**：科目折线趋势 + 各次考试明细表
3. **德育**：事件时间线 + 加减分合计
4. **值日**：参与记录与评价

## 系统设置

- 学期管理：新建（可从上学期复制名册）、切换当前学期、归档（只读）
- 数据：全量 JSON 导出/导入（导入前强制先导出一份当前数据）、Excel 全量导出
- 关于：版本、备份说明

## 打印（贯穿）

点名表、成绩条、值日表提供打印样式（`@media print` 隐藏侧栏/顶栏）；M4 检查 WebView2 打印行为。
