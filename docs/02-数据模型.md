# 02 · 数据模型

## 全局约定

- 主键 `id`：字符串 nanoid(12)
- 日期 `YYYY-MM-DD`，时间戳 ISO 字符串，一律存字符串
- 业务记录同时挂 `student_id + semester_id`（反规范化，班级规模小，换取查询直白）
- 删除一律硬删（单机工具，不做回收站；备份兜底）

## 表

### semesters 学期

| 字段                  | 类型    | 说明                                  |
| --------------------- | ------- | ------------------------------------- |
| id                    | string  | 如 `2026-2027-1`（学年-学期号）       |
| name                  | string  | `2026-2027学年 第一学期`              |
| start_date / end_date | date    |                                       |
| is_active             | boolean | 全表仅一个 true；「当前学期」由它决定 |

### students 学生（跨学期实体）

| 字段                    | 类型                      | 说明                 |
| ----------------------- | ------------------------- | -------------------- |
| id                      | string                    |                      |
| name                    | string                    | 必填                 |
| student_no              | string                    | 学号，全表唯一，必填 |
| gender                  | `male`/`female`/`unknown` |                      |
| birth_date              | date?                     |                      |
| parent_contact          | string?                   | 家长电话             |
| address                 | string?                   |                      |
| notes                   | string?                   |                      |
| created_at / updated_at | ISO                       |                      |

> 不收身份证号等强敏感字段，即使名单里有也不导入。

### enrollments 名册（学期×学生）

| 字段                     | 类型                       | 说明             |
| ------------------------ | -------------------------- | ---------------- |
| id                       | string                     |                  |
| semester_id / student_id | string                     | 联合唯一         |
| seat_no                  | number?                    | 座位号           |
| status                   | `active`/`transferred_out` | 转出不删历史记录 |

### attendance 考勤（全量记录策略）

| 字段                     | 类型                                                      | 说明                                    |
| ------------------------ | --------------------------------------------------------- | --------------------------------------- |
| id                       | string                                                    |                                         |
| semester_id / student_id | string                                                    |                                         |
| date                     | date                                                      |                                         |
| status                   | `present`/`late`/`sick`/`personal`/`absent`/`early_leave` | 当天每生一行，`(student_id, date)` 唯一 |
| remark                   | string?                                                   |                                         |

### 假期（已实现）

`semesters.holidays: string[]`（YYYY-MM-DD，非索引字段，无需 schema 升版）。管理入口在系统设置页「假期管理」卡（当前学期）；`workdaysBetween(start, end, holidays)` 计算应出勤时排除；归档学期也可修改（属元数据）。360 视图的"应出勤工作日/缺记录"随假期联动。

减压路径补充：录入页"全勤，直接保存"让全勤日只点一次；若仍嫌繁琐，可在历史查询加"按周补全勤"批量操作（备选，未实现）。

> 全量 vs 只记异常：选**全量**。**与教学日历的"只存差异"并不矛盾**：日历基线可从星期推导（存例外零损失）；考勤的"全员出勤"基线依赖"老师当天录过"这一行为确认，确认本身必须落库——否则缺记录提醒无从谈起。UI 层"默认出勤只点异常"是录入差分，不是存储差分。**考勤日期必须在学期起止范围内**（repo 层校验）；开学前活动应调整学期 start_date，而非往范围外录。出勤率统计零脑力、Excel 对齐简单；一个学期约 1 万行，两种存储都毫无压力。UI 侧做成「默认全员出勤，只点异常」，录入成本不变。

### exams 考试

| 字段        | 类型                                | 说明       |
| ----------- | ----------------------------------- | ---------- |
| id          | string                              |            |
| semester_id | string                              |            |
| name        | string                              | `期中考试` |
| date        | date                                |            |
| type        | `daily`/`monthly`/`midterm`/`final` |            |

### scores 成绩

| 字段                               | 类型    | 说明                                             |
| ---------------------------------- | ------- | ------------------------------------------------ |
| id                                 | string  |                                                  |
| exam_id / student_id / semester_id | string  |                                                  |
| subject                            | string  | `语文`，自由字符串                               |
| score                              | number? | null = 缺考；(exam_id, student_id, subject) 唯一 |

### discipline_events 德育事件

| 字段                     | 类型           | 说明                     |
| ------------------------ | -------------- | ------------------------ |
| id                       | string         |                          |
| semester_id / student_id | string         |                          |
| date                     | date           |                          |
| direction                | `plus`/`minus` | 加分/扣分                |
| category                 | string         | 纪律/卫生/文明/助人/其他 |
| points                   | number?        | 分值（可不记分只记事）   |
| description              | string         | 必填                     |

### duty_records 值日（初版，M3 可能微调）

| 字段        | 类型               | 说明             |
| ----------- | ------------------ | ---------------- |
| id          | string             |                  |
| semester_id | string             |                  |
| date        | date               |                  |
| group_name  | string?            | 值日组名         |
| student_ids | string[]           | 参与学生         |
| area        | string             | 教室/包干区/其他 |
| evaluation  | `good`/`ok`/`poor` |                  |
| remark      | string?            |                  |

### documents 文档台账

| 字段        | 类型    | 说明                                |
| ----------- | ------- | ----------------------------------- |
| id          | string  |                                     |
| semester_id | string  |                                     |
| title       | string  |                                     |
| category    | string  | 通知/计划/总结/其他                 |
| date        | date    |                                     |
| summary     | string? | 摘要/登记内容                       |
| attachment? | blob    | web 期存 IndexedDB；M4 迁到磁盘文件 |

### settings 键值

`key` → `value(json)`。现有键：`currentSemesterId`、`lastBackupAt`、UI 偏好。
